# Open Questions for Fortune

Before Phase 1 begins in earnest, the following need a decision or confirmation:

1. **CMI hub-capacity threshold** — is 150m² per order a reasonable default trigger for
   automatic CMI-routing suggestion, or does this vary meaningfully by hub/season?
2. **Trade account approval SLA** — what turnaround time should buyers be told to expect while
   an application is under manual review?
3. **Custom-size request flow** — when a buyer wants a size outside the AAAMSA-tested range,
   should the platform auto-generate an RFQ, or require a phone/email conversation first?
4. **Besfleet booking integration** — does Besfleet have (or plan) an API/booking system this
   platform can call directly, or is fragile-goods dispatch a manual handoff for now?
5. **Existing invoicing system integration** — for Trade Account Terms orders, should this
   platform push completed orders into the existing Besbpo/Aluminium Store invoicing system
   automatically, or is that still a manual reconciliation step for now (as it is on
   Roofsteel)?
6. **Repo ownership and initial team** — confirming repo ownership sits with Besbpo Group
   (as on Roofsteel) and who the initial reviewing engineers are for the Phase 5 human PR
   review step.
